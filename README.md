# build-token-architecture-slides

这是一个用于生成与修订**架构可视化 HTML 页面**的技能型仓库，核心目标是：

- 基于真实代码或文档事实构建架构说明页
- 以主题 token（CSS / JSON / Tailwind preset 等）作为视觉来源
- 输出适合截图、演示与文档嵌入（如 Word）的页面

## 仓库分析（结构与职责）

### 1. `SKILL.md`
仓库主说明文件，定义了该技能的使用范围、工作流程、版式要求、中文文案规则与质量门禁。

### 2. `assets/`
内置视觉主题库，包含大量风格目录（约 125 个）。每个主题目录通常包含：

- `*-globals.css`
- `*-variables.css`
- `*-tokens.json`
- `*-shadcn-theme.json`
- `*-tailwind-preset.js`

并通过 `assets/styles-overview.md` 提供风格总览。

### 3. `references/layout-contract.md`
版式契约，约束内容密度、分组方式、构图类型、纵横比、中文表达与拒收条件，用于保证页面可读性与信息完整度。

### 4. `scripts/validate_slides.ps1`
静态校验脚本，用于检查：

- HTML 标签结构平衡
- 是否存在 `class="slide"` 页面
- 可见文案是否包含斜杠 `/`
- 文本密度与卡片内容稀疏问题
- 若干容易导致布局空洞的 CSS 写法

## 核心演进与设计原则

经过实战检验与竞赛评审标准反哺，本技能沉淀了以下关键准则：

1. **Word 截图与评审视角优先**：
   - 目标载体以“嵌入 Word 申报书 / PPT / 评审 PDF”为第一优先级。
   - **字号放大与卡片文案克制**：卡片内严禁堆砌长篇大论，提炼高信号架构逻辑与状态参数，腾出空间放大正文字号（14px~18px）与标题字号（18px~24px），确保缩放后依然清晰可辨。
   - **极窄内边距（Padding 压缩）**：压低 SVG 容器与外围卡片的冗余内边距，让核心图表吃满视口宽度。
   - **拒绝花哨交互**：不向页面注入缩放按钮、悬浮工具栏等非演示性控件，保持静态高保真版面纯净。
2. **S-Flow 蛇形折返流与平滑曲线转角**：
   - 长流程管道（4~8 阶段）坚决采用 2~3 行折返布局（第 1 行左至右，第 2 行右至左，第 3 行左至右），破解单行横排过窄、文字无法辨识的硬伤。
   - 行间衔接一律采用平滑圆润的三次/二次贝塞尔平滑曲线（`<path d="..." fill="none" />`），消除生硬突兀的 90 度折角，呈现自然的闭环演进动势。
3. **深扎源码实证（Codebase-First Grounding）**：
   - 构建页面前必须深查目标项目的真实源码（智能体工作流、状态机、数据 Schema、接口规范），实体命名与流转关系百分之百真实可信，严禁空洞套话。
4. **图文互补共生**：
   - 架构图负责提纲挈领呈现心智模型与空间拓扑；技术报告与申报正文负责展开深入机制论证与实测数据，两者协同印证。

## 18 大核心布局范式 (18 Layout Archetypes)

技能全面内化支持 18 种标准化视觉与空间构图范式，覆盖技术方案、学术答辩与评审报告的全场景表达：

| 序号 | 布局范式 | 英文标识 | 核心视觉特征 | 典型适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **便当盒布局** | Bento Grid | 日式便当盒不规则网格，高密度模块化组合 | 核心系统全景概览、多模块能力矩阵、全能特性大图 |
| 2 | **瀑布流布局** | Masonry Flow | 不等高卡片流式交错拼合，自然无断裂 | 多模态资源中心、异构案例展示、非对称评测证据集 |
| 3 | **分屏布局** | Split Screen | 左右 50:50 或 60:40 对照，空间对比与平衡 | 破局对比（痛点 vs 解法）、理论推导 vs 工程实现 |
| 4 | **全屏滚动布局** | Full Page Scroll | 单屏充满视口，场景自包含，沉浸式切换 | 章节开篇愿景、单机制深度沉浸解析、独立答辩页 |
| 5 | **垂直时间线布局** | Vertical Timeline | 垂直轴线贯穿，节点与卡片沿轴有序交错 | 研发演进历程、自适应学习路径推进、版本迭代时序 |
| 6 | **卡片堆叠布局** | Card Stack | Z 轴层叠配合微量偏移与阴影，制造立体景深 | 多层纵深防御、安全策略体系、分层协议栈、快照栈 |
| 7 | **固定侧边栏布局** | Fixed Sidebar | 左侧固定导航/目录树，右侧为主工作区与画布 | 系统配置控制台架构、知识库目录管理、工作区总控 |
| 8 | **杂志网格布局** | Magazine Grid | 印刷杂志多栏排版，主卡跨栏破格，首字下沉 | 学术背景与政策依据解读、重大行业痛点长篇剖析 |
| 9 | **全屏英雄区布局** | Fullscreen Hero | 特大号主标、定位标语与居中核心架构枢纽 | 方案申报封面/首屏、杀手锏功能发布、技术突破宣发 |
| 10 | **F型布局** | F-Pattern Layout | 遵循眼动 F 型动线（顶栏宽扫、左侧锚定、次级扫描） | 内容密集型技术规格书、多智能体协议清单、排障说明 |
| 11 | **Z型布局** | Z-Pattern Layout | 遵循眼动 Z 字折线（左上->右上->左下->右下） | 着陆页架构、商业模式与推广路径、三大破局点串联 |
| 12 | **圣杯布局** | Holy Grail Layout | 经典三栏式：页眉 + 左导航/中画布/右监控 + 页脚 | 工作区与代码实操体系、IDE 工作台架构、三位一体范式 |
| 13 | **仪表盘布局** | Dashboard Layout | 数据驱动监控面板，顶栏 KPI 大卡 + 图表 + 拓扑 | 多智能体运行看板、学生画像监控、模型开销评测 |
| 14 | **非对称网格** | Asymmetric Grid | 不规则列宽比例（如 7:3、5:3:4），视觉张力强 | 突出颠覆性创新模块（大面积核心）、差异化竞品对比 |
| 15 | **视差滚动** | Parallax Sections | 前景与背景多层深度展开，呈现空间景深 | 基础设施到上层应用的层级穿透、技术演进三重境界 |
| 16 | **滚动叙事** | Scrollytelling | Sticky 画布钉在视口，文字推进触发画布演化 | 多智能体时序调度推演、闭环逐步推演、状态机步进 |
| 17 | **视差杂志** | Parallax Editorial | 暖纸底色，sticky 图文交织，章节编号与优雅首字下沉 | 教育哲学理念、人机协同理论基石、学术化科研长文 |

## 典型使用流程

1. 选择主题来源（用户提供或 `assets/` 内置主题）
2. 阅读并映射 token 与主题语义
3. 深入阅读项目真实源码与架构事实，提炼核心实体与拓扑关系
4. 按 `layout-contract` 组织页面结构、S-Flow 动线与中文文案
5. 运行校验脚本并修正问题

## 校验命令

```powershell
powershell -ExecutionPolicy Bypass -File scripts/validate_slides.ps1 -Path <HTML绝对路径>
```

## 适用场景

- 国家级/省部级创新创业大赛技术架构方案页
- 高校与科研项目技术路线图、全景闭环图
- 系统流程、多智能体协同流水线与状态转换图
- 面向截图交付、Word/PPT 嵌入的高保真演示型 HTML 文档
